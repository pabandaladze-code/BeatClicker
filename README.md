# Sound Spy — 2D Stealth Game

Проект по дисциплине **Системы Языков Программирования (СЯП)**.

## Лабораторная работа №1: Настройка окружения и базовая архитектура

### Описание
Инициализация игрового движка Pygame, создание главного игрового цикла и настройка модульной структуры проекта.

### Стек технологий
* **Язык программирования:** Python 3.12
* **Библиотека:** Pygame 2.6.1
* **IDE:** Visual Studio

### Структура проекта
* `main.py` — Точка входа в программу, инициализация Pygame и главный игровой цикл.
* `constants.py` — Глобальные константы (параметры окна, FPS, RGB-цвета).
