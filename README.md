# Вариант 4. «Ритм-Автомат» (Beat Clicker)

Проект по дисциплине **Системы языков программирования (СЯП)**.

## Лабораторные работы №1 и №2

### Описание
Визуальный кликер на Pygame. Ноты (круги) появляются на экране по таймингам из внешнего файла `beatmap.json`. Вокруг мишени сужается кольцо, и клик мыши проверяется на точность попадания в такт. Результаты сохраняются в CSV-файл.

### Структура проекта
* `main.py` — Главный игровой цикл и ритм-логика.
* `constants.py` — Глобальные параметры и цвета.
* `beatmap.json` — Конфигурация трека и нот.
* `beat_scores.csv` — Таблица рекордов.

### Запуск
```bash
pip install pygame
python main.py
